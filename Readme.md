# 🏥 Hospital Management System

This is a **Full Stack Hospital Management System** built using **React** for the frontend, **Spring Boot** for the backend, and **MySQL** as the database.

---

## 🚀 Tech Stack

- ⚛️ React.js (Frontend)
- 🌱 Spring Boot (Backend)
- 🛢️ MySQL Workbench (Database)
- 📦 Maven (Project Management)
- 🎨 Bootstrap / CSS (Styling)

---

## 📁 Project Structure

hospital-management-system/ ├── frontend/ # React app ├── backend/ # Spring Boot app └── README.md # Project documentation
---

## 🔧 Features

- Patient Registration & Management
- Doctor Profiles & Schedules
- Appointment Booking
- Medical Records Management
- Login & Role-based Access (Admin, Doctor, Patient)
- Dashboard with Stats

---

## 🛠️ Installation and Setup

### 📌 Prerequisites

- Node.js and npm
- MySQL Server
- Java JDK (17+ recommended)
- Maven
- Spring Boot
- Git

---

### 🖥️ Backend (Spring Boot)

1. Open the `backend/` folder in your IDE (IntelliJ or Eclipse).
2. Update the `application.properties` file with your MySQL database credentials.
3. Run the backend server:

```CMD
mvn spring-boot:run



🌐 Frontend (React)
Open a terminal and navigate to the frontend/ folder:


cd frontend
Install dependencies:


npm install
Start the React app:

npm start
✅ Database Setup (MySQL)
Open MySQL Workbench.

Create a database (e.g., hospital_db).

Update your application.properties to point to it.

If using Spring JPA with auto DDL, it will create tables automatically. Or import a schema manually.
